07 · Six rules
Prompt craft

The CRAFT-V method.

Six parts. You don't always write all six. The point is enough direction for the AI to be useful — and a built-in habit of verification.

C
Context
What's the situation?
R
Role
Who should AI act as?
A
Action
What exactly to do?
F
Format
What should output look like?
T
Tone
How should it sound?
V
Verify
What to check before sending?
08 · CRAFT-V
Live vote · Mentimeter

Same AI. Different output.

Both prompts are reasonable. Which one will produce a more useful answer for a regional MD on Monday morning?

Prompt A
“Act as a business analyst. Review this monthly sales report and identify the key trends and risks. Output as a short summary.”

Asks for: observations

Prompt B
“Act as a business analyst. Review this monthly sales report for a regional MD. Identify the key trends, anomalies, and risks — and the three actions the MD should take this week. Output as a table: Observation · Evidence · Implication · Recommended action · Confidence. List any assumptions.”

Asks for: decisions

09 · Prompt battle
Pivot

Microsoft AI Evnironment at Filtrona.

We already have a Microsoft-first starting point. Use Copilot for work-related support, and use IT guidance when a use case needs company data, custom agents or automation.

External tools are useful for learning and inspiration, but Filtrona work content stays inside approved tools. Explore widely. Work safely.

The practical rule

  • Daily work: start with Microsoft 365 Copilot Chat and the Copilot features in approved Microsoft apps.
  • Repeated work: look for Power Automate, Forms, SharePoint, Outlook and Teams patterns.
  • Advanced work: bring the use case to IT when it needs work-data grounding, custom agents or premium connectors.
  • Public AI: fine for generic learning; not for customer, supplier, finance, employee or confidential Filtrona content.
10 · Microsoft-first
Get the names right

The Copilot spectrum.

Do not memorize license names. Remember the business difference: public web help, work-data help, and custom workflow help.

Safe default

Copilot Chat

Ask · draft · summarize
  • Good for general work assistance
  • Web-grounded answers
  • Useful for prompts, checklists and rewrites
  • Not automatically reading your whole work universe
Work context

M365 Copilot in apps

Use · Word · Excel · Teams
  • Helps inside the apps people already use
  • Useful for meetings, email, documents and analysis
  • Best when content and permissions are clean
  • Always verify names, numbers, dates and policy statements
Scale it

Agents & workflows

Build · automate · govern
  • Power Automate for repeatable process steps
  • SharePoint/Forms/Teams for intake and routing
  • Copilot Studio for approved agent scenarios
  • Bring IT in when data, access or approvals matter

Detailed entitlements and pricing belong in the resource page. In the live session, the decision rule is simpler: safe default → work context → governed scale.

14 · AI@Filtrona
Workflow patterns, not one-off projects

From manual chasing to managed flow.

Weekly reports, approval requests and visitor logs look different — but the digital pattern is almost the same.

Capture

Use Forms, SharePoint lists, Excel Online or Power Apps to collect clean inputs once.

Route

Use Power Automate for approvals, reminders, ownership, timestamps and escalation.

Track

Create visibility: status, ageing, bottlenecks, pending actions and audit trail.

Assist

Use Copilot to draft summaries, explain trends and prepare follow-up — with human review.

Expansion idea: the same pattern can support weekly reporting, eCAPEX-style approvals, visitor registration, issue logs, training requests and many other repeatable processes.

Lesson: AI value compounds when we connect capture → route → track → assist, instead of treating every request as a separate manual task.

18 · Two columns, one rule
Live quiz · Mentimeter

Quick quiz.

Question

“Can I upload a customer pricing workbook to a free public AI website if I remove the filename and the customer's name?”

Yes Depends No

The principle

Classification follows content, not metadata.

Pricing terms, margin structure, customer identity — these are sensitive whether the file is called pricing-Q3.xlsx or untitled.xlsx.

The test: if a competitor or this customer saw the content, would there be a problem? If yes — it doesn't go in a public tool, no matter how you rename it.
